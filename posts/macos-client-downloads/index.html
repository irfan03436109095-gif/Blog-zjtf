macOS 客户端下载：Clash Verge Rev、v2rayN 与 Mac 芯片选择

酌酒听风2026-10-11— 次阅读
使用教程软件下载

Mac 下载客户端时，先查看芯片型号和 macOS 版本。Apple 芯片与 Intel 的安装包可能不同，适用的最低系统版本也需要单独核对。

下载入口：Clash Verge Rev 正式版 · v2rayN 正式版

第一步：确认芯片和系统版本

点击苹果菜单，打开“关于本机”，查看“芯片 / 处理器”和 macOS 版本。

你的 Mac Clash Verge Rev 常见文件结尾 v2rayN 常见文件名
Apple 芯片，例如 M 系列 aarch64.dmg v2rayN-macos-arm64.dmg
Intel 处理器 x64.dmg v2rayN-macos-64.dmg

以上 DMG 已在本次正式版附件中核对。发布页的 .app.tar.gz、.zip、.sig 和 Source code 用途各不相同；第一次安装时，按项目说明选择对应 DMG 更容易判断下一步。

截至本次核对，Clash Verge Rev 安装文档要求 macOS 12 及以上；v2rayN 文件说明要求 macOS 13.6 及以上。项目首页和旧教程的要求可能不同，下载前以当前安装说明与所选版本的发布说明为准。

第二步：安装并打开

  1. 进入上面的项目正式发布页，展开 Assets。
  2. 下载与芯片匹配的 DMG，打开后把应用移到“应用程序”。
  3. 从“应用程序”启动，按软件说明完成必要的初始化。
  4. 如果系统提示无法验证开发者或应用无法打开，先确认下载来源与系统兼容性，再参照该项目的 Mac 安装说明处理。

Clash Verge Rev 的安装细节可查看官方文档，v2rayN 的文件与安装提示可查看官方 Wiki。

第三步：选择对应订阅

软件 从服务商后台选择 安装后的主要操作
Clash Verge Rev Clash / mihomo 兼容订阅 导入订阅、选中配置、选节点、开启系统代理
v2rayN v2rayN / V2Ray 兼容订阅 添加订阅分组、更新、选节点、检查系统代理

Clash Verge Rev 的配置流程可参照官方快速入门；v2rayN 的格式要求可参照官方订阅说明。

先用浏览器打开需要的网页，确认能够刷新。需要让不支持系统代理的程序连接时，再查看客户端的 TUN 文档。切换客户端前，先关闭原客户端的系统代理或连接，便于判断哪款软件正在处理流量。

Hiddify 也是一个可选入口

如果你已经在安卓手机上使用 Hiddify，可在Hiddify 正式发布页查看 Mac 安装包。本次正式版附件包含 Hiddify-MacOS.dmg；具体芯片与系统要求、初始化流程查看项目说明和安装文档。

选软件时，先确认它能读取服务商给出的配置。界面相近并不代表所有协议参数或规则文件都能直接复用。
