1️⃣ 登录机场

4️⃣ 点击《导入到Clash》

其他

首次运行 Clash Meta for Android 的注意事项 部分国产安卓手机会 ⛔ 阻止软件安装，需要退出软件的安全模式，以完成 Clash Meta for Android 的正常安装。 确定已安装正确的版本，一般安卓设备安装 arm 版本。不知道安装哪个版本的，直接安装 universal 版本。 Clash Meta 开启 VPN 代理时需要输入解锁密码以完成代理设置。 成功运行后屏幕顶部会显示小钥匙标志，证明已正确开启 Clash Meta 软件服务。

设置代理模式

前往「代理」界面，根据您的需求选择代理模式：

全局连接 | Global：代理所有流量

适用于不依赖国内服务的用户。 對国外流量效果非常好，国内流量會被減速。 此模式下 ? ​不能选 DIRECT 和 REJECT 节点​，它们会导致无法上网。

规则判断 | Rules：只代理国外流量

适用于同時使用国內外服务的用戶。 国内流量不会消耗套餐流量。 在国内網站上查询 IP 得到的是本地 IP 地址。 在国外网站上查询 IP 得到的是代理 IP 地址。 分流规则无法做到全面且具有時效性，如果遇到以下情況，请尝试全局代理。

无法打开国际网站； 加载国际网站缓慢； 无法解锁 Netflix / Spotify 等区域限制內容。

直接连接 | Direct：不代理任何流量

选择此模式将导致无法翻墙，与关闭 VPN 的效果一致。

Clash Meta for Android 异常退出怎么办？ Clash Meta for Android 可能被杀后台，请确认安卓系统的电池选项，确保在设置中已为软件开启常驻后台。 在 Clash Meta for Android 软件中可选择「自动重启」，这样 Clash Meta for Android 会保持后台常驻运行。

安全注意事项

不要使用国产浏览器访问境外网站，防止泄露浏览器历史记录。

翻墙时也不要使用国产的 QQ、搜狗输入法，有一定程度的安全隐患。

Surfboard 冲浪板和 Clash 使用方法相似，但使用不同格式的配置文件。
